## `solicitudes/`
Ejemplo end-to-end de un sistema de gestión de solicitudes de trámite:

| Archivo | Etapa | Descripción |
|---------|-------|-------------|
| `001-discovery.md` | Discovery | Notas de la primera reunión |
| `actors.md` | Análisis | Actores identificados |
| `open-questions.md` | Análisis | Preguntas abiertas |
| `requests.md` | Épicas | Épica de gestión de solicitudes |
| `US-001.md` | Historias | Historia lista (pasa INVEST) |
| `US-014.md` | Historias | Historia NO lista (falla INVEST) |
| `mvp.md` | Priorización | Clasificación MoSCoW |
| `requirements-matrix.md` | Trazabilidad | Problema → Test |

Usá estos archivos como referencia de formato y nivel de detalle esperado.
