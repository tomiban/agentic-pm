# EP-01 — Gestión de solicitudes

- **Módulo:** MOD-03 (Solicitudes)
- **Problema que resuelve:** PROB-01 (Demoras en registrar solicitudes)
- **Objetivo:** OBJ-01 (Reducir tiempo de registro)

## Descripción
Capacidad de crear, consultar, modificar, cancelar, aprobar y rechazar solicitudes de trámite.

## Historias
- [ ] US-001 — Crear solicitud
- [ ] US-002 — Consultar solicitud

## Criterios de finalización
- Un ciudadano puede registrar una solicitud end-to-end.
- Un operador puede aprobarla o rechazarla con trazabilidad.
