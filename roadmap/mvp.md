# MVP — Priorización MoSCoW (EJEMPLO)

| Backlog | Prioridad | Justificación | Épica |
|---------|-----------|---------------|-------|
| Autenticación | MUST | Habilita todo lo demás | EP-00 |
| Usuarios | MUST | Requerido para operar | EP-00 |
| Crear solicitud | MUST | Núcleo del problema (PROB-01) | EP-01 |
| Consultar solicitud | MUST | Sin consulta el trámite no cierra | EP-01 |
| Notificaciones | SHOULD | Mejora, no bloquea MVP | EP-03 |
| Reportes | COULD | Valor secundario | EP-04 |
| Dashboard avanzado | WON'T | Fuera de alcance | EP-05 |

## Definición del MVP
> Conjunto mínimo de features MUST que resuelve el problema principal (registro lento y con errores).

### Incluye
- Autenticación, Usuarios, Crear solicitud, Consultar solicitud

### Excluye
- Notificaciones, Reportes, Dashboard avanzado

## Versiones
- **MVP:** registro y consulta de solicitudes
- **V1:** + notificaciones + administración básica
- **V2:** + reportes + dashboard
