- **Épica:** EP-01
- **Actor:** ACT-01 (Ciudadano)
- **Prioridad:** MUST
- **Estimación:** 5
- **Estado INVEST:** ✅ Lista

## Historia
> Como ciudadano, quiero crear una solicitud para iniciar un trámite.

## Criterios de aceptación
```gherkin
Given que el ciudadano está autenticado
When completa todos los campos obligatorios
And confirma la solicitud
Then el sistema debe registrar la solicitud
And asignarle un identificador único
```

## Edge cases
- [x] Falta un campo obligatorio → el sistema muestra el error y no registra
- [x] Archivo adjunto inválido → rechaza con mensaje específico
- [x] El usuario abandona → borrador no persiste (a confirmar, Q-03)
- [x] Solicitud duplicada → permite duplicados (regla BR-03, a confirmar)
- [x] Servicio externo caído → encola y reintenta
- [x] Sin permisos → 403
