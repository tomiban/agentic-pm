# Registro de cambios

Todo cambio sobre un requisito ya validado se registra acá. El requisito original
no se borra: se marca como reemplazado.

## Clasificación

| Tipo | Descripción |
|------|-------------|
| Corrección | El requisito estaba mal escrito |
| Aclaración | Faltaba un detalle, sin impacto de alcance |
| Alcance nuevo | Se agrega funcionalidad → reestimar y re-priorizar |
| Eliminación | Se saca del alcance → verificar dependencias |
| Contradicción | Dos requisitos incompatibles → resolver con el cliente |
